# Tharini's Sweet Twenty-One

Create a highly beautiful, emotional, cute and interactive birthday website for my best friend **Tharini**, who is turning **21 on 26 September 2026**.

The website should feel like a **personal animated birthday story made specifically for her**, not like a generic birthday template.

The overall vibe should be:
💗 Cute
🌸 Feminine
✨ Dreamy
🎀 Playful
🥹 Emotional
🫶 Warm
🌙 Magical
💌 Personal

Use a soft **pink + lavender + blush + cream + white** color palette with subtle gradients, glowing elements, sparkles, floating hearts, flowers and cute animations.

Use elegant typography with a combination of:
* A beautiful modern rounded font for normal text
* A handwritten/cursive font for emotional messages
* Large elegant typography for important moments

Make the entire website responsive, especially beautiful on mobile because I will probably send it to her as a birthday link.

And make it a timer that makes it more special: include an interactive countdown timer counting down to her 21st birthday on 26 September 2026 (or celebrating when reached) with cute glowing time cards and celebratory sparkles.
